# 浜名湖うなぎ

静岡県浜名湖産うなぎの魅力を紹介するランディングページ。

## セクション

- ヒーロー（キャッチコピー）
- About（浜名湖うなぎとは）
- 3つの魅力（産地直送 / 伝統の技術 / 栄養価）
- 職人の技（串打ち → 白焼き → 蒸し → 蒲焼き）
- ギャラリー
- CTA（お問い合わせ）

## 技術スタック

- HTML / CSS（CSS変数、Grid/Flexbox、レスポンシブ）
- JavaScript（IntersectionObserver、モバイルメニュー）
- Unsplash（フリー画像）

## 開発

```bash
npx serve .
```
